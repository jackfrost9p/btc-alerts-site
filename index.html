BTC Streak Alerts

BTC Streak Alerts is a small program that watches public cryptocurrency exchange data and fires a push notification when BTC-USD closes three consecutive 15-minute candles in the same direction — three rising or three falling.

This is a private tool, built and run by one person for their own use. It is not a product, not a subscription, and not open to sign-ups. There is no mailing list and no way to join. This page exists only to describe what the software does.

How it works

  • A scheduled job polls 15-minute BTC-USD candles from a public exchange feed.
  • Closed candles are compared; three closes in a row in the same direction counts as a streak.
  • Each streak alerts once. The alert is only recorded as sent after the push actually succeeds, so a failed delivery retries instead of vanishing.
  • Delivery goes to a single private push channel. Its destination and credentials live in a local environment file — never in this repository and never on this page.

What an alert looks like

BTC-USD up 3 GREEN 15m candles close $118,400 | streak +0.62% | last +0.21%
BTC-USD down 3 RED 15m candles close $116,950 | streak -0.74% | last -0.19%

Frequency

Alert frequency varies with market activity. Quiet stretches produce almost nothing; choppy ones can produce a few dozen alerts in a day.

History

An earlier version of this project delivered alerts over SMS. That path has been retired, along with its carrier registration, opt-in keyword, and phone number. Notifications now go over a push service instead, and no phone numbers are involved at any point.

Not financial advice

These alerts report that a price pattern occurred. They are not a recommendation to buy or sell anything, and the pattern has not been shown to predict future prices.
