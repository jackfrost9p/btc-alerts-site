BTC Streak Alerts

Privacy

Last updated: August 21, 2026

This site collects nothing about you, and the tool it describes has no users other than its author.

There is no sign-up, no account, no subscriber list, and no personal data to share, sell, or disclose — because none is ever collected.

This website

These pages are static HTML. They set no cookies, run no analytics, load no third-party scripts or fonts, and record nothing about visitors. The only logs that exist are the ordinary web-server request logs kept by the static host, which the author does not use for any purpose.

The alerting tool

The program described on the home page reads public market data and sends notifications to one private channel belonging to its author. It has no subscribers, so it stores no contact details of any kind. Nothing about any other person passes through it.

Phone numbers

An earlier version of this project sent alerts by SMS. That version has been retired: the phone number is no longer in service for this project, the carrier campaign is closed, and no phone numbers are stored or used anywhere in the current system.

Credentials

The tool's notification settings and API credentials are kept in a local environment file that is excluded from version control. They are not published on this site or in the repository.

Changes

Any change will be posted on this page with an updated date above.
